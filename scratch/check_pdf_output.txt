111. 금융기관의 배포 보안 강화를 위해 다음과 같은 
통제 요건을 설계하고자 한다. 이에 가장 부합하는 
접근 제어 방식은?
  ① 역할 기반 접근 제어(RBAC)를 적용해 운영자와 
배포 승인자를 분리하고, 서비스 계정은 고정 
비밀번호를 공유하되 변경 이력만 관리한다.
  ② 속성 기반 접근 제어(ABAC)를 적용해 시간, 승인 
상태, 장애 여부 같은 조건에 따라 권한을 판단
하고, 서비스 계정은 비밀관리 시스템에서 단기 
자격증명으로 발급받아 사용한다.
  ③ 임의 접근 제어(DAC)로 저장소 소유자가 권한을 
위임할 수 있게 하고, 긴급 상황에서는 운영자가 
필요한 권한을 직접 추가한다.
  ④ 강제 접근 제어(MAC)로 모든 사용자의 접근 등급을 
통합 관리하고, 배포 승인과 운영 권한은 시스템 
관리자가 수동으로 일괄 승인한다.

함으로써 네트워크 전체의 에너지 효율성을 
제고하고 통신 지연을 제거할 수 있다.

117. 다음 중에서 웹 응용 프로그램에 대한 DoS 공격 
유형에 대한 설명으로 가장 적절하지 않은 것은?
  ① 동적 HTTP Reply 공격은 웹 페이지 응답 메시지를 
지속적으로 요구하는 공격이다.
  ② Slow HTTP Header DoS 공격은 서버로 전달할 
HTTP 메시지의 헤더 정보를 비정상적으로 조작해 
웹 서버가 헤더 정보를 완전히 수신할 때까지 
연결을 유지하도록 하는 공격이다.
  ③ Slow HTTP POST 공격은 사용자가 웹 서버에 
아이디, 패스워드, 게시글 등을 전송할 때 
POST 메소드를 이용하여 서버와의 커넥션을 
오래 유지해 웹서버가 정상적인 사용자 접속을 
받아들일 수 없게 하는 공격이다.
  ④ HTTP GET Flooding 공격은 GET 메소드를 통해 
특정 페이지를 무한대로 요구하는 공격이다. 
118. 다음 중 블록체인 네트워크에서 이클립스 공격

하여 블록 생성과 체인 선택을 좌우하고, 특정 
거래를 되돌리거나 이중지불을 수행할 수 있게 
하는 합의(Consensus) 공격이다.
  ② 공격자가 다수의 가짜 노드를 생성해 네트워크

다수결을 장악하거나 네트워크 신뢰 모델을 붕
괴시키는 공격이다.
  ③ 공격자가 특정 노드의 피어 연결을 의도적으로 
편향 또는 고립시켜 해당 노드가 공격자가 통제

인식, 거래 전파, 검증 판단에 영향을 주는 네

  ④ 생략

119. 다음은 방화벽에 대한 설명이다. 이 중 가장 
적절하지 않은 설명은?
  ① 상태 기반 방화벽(Stateful Firewall)은 연결 상태 
정보를 추적하여 패킷을 필터링한다.
  ② 애플리케이션 방화벽은 HTTP, FTP 등 응용계층 
트래픽을 제어할 수 있다.
  ③ 패킷 필터링 방화벽은 데이터의 내용(payload)을 
깊이 분석하여 공격을 탐지한다.
  ④ 방화벽은 네트워크 경계에서 접근제어 정책을 
적용한다.
120. 다음은 네트워크 보안 기술 및 대표적인 네트워크 
공격 유형에 대한 설명이다. 이 중 가장 적절하지 
않은 설명은?
  ① 네트워크 세그멘테이션(Network Segmentation)은 
네트워크를 여러 보안 영역으로 논리적 또는 
물리적으로 분리하여 공격 확산을 방지하고 
보안 정책 적용을 용이하게 하는 보안 기법이다.
  ② TLS(Transport Layer Security)는 통신 데이터의 
기밀성과 무결성 기능 대신에 안전한 네트워크 
라우팅 기능을 제공하기 위한 보안 프로토콜이다.
  ③ DNSSEC(Domain Name System Security Extensions)는 
DNS 응답 데이터의 무결성(integrity)과 출처 인증
(authentication of origin)을 제공하기 위한 보안 
기술이다.
  ④ Smurf Attack은 네트워크 자원을 소모시켜 정상
적인 서비스를 제공하지 못하게 하는 서비스 거부 
공격(DoS) 유형에 해당한다.
